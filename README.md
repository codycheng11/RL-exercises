<h2>Overview</h2>

This summer, I implemented RL algorithms in two common Gymnasium environments: Q-learning for MountainCar, and deep Q-networks for CartPole.
These were based on the methods covered in David Silver's RL lectures, Sutton & Barto's "Reinforcement Learning: An Introduction," and [Mnih et
al's 2015 paper](https://www.nature.com/articles/nature14236) on implementing deep Q-networks.
